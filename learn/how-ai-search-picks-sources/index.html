Learn / Get found in AI answers

Lesson 1 of 3

How AI search picks what to quote

When someone asks ChatGPT, Perplexity or Google’s AI for the best design studio or the cheapest way to run Meta ads, the answer is built from web pages. Here’s roughly how those pages get picked, and the first things to check on your own site.

By Neeraj, NMX Labs23 November 20265 min read

Quick summary

  • AI search tools look things up on the web, pick a handful of pages, then summarise them. If they can’t find or crawl your page, you can’t be quoted.
  • Make sure AI crawlers aren’t blocked in robots.txt, for example OAI-SearchBot for ChatGPT search and PerplexityBot for Perplexity.
  • ChatGPT search draws on third-party search providers, so being well indexed in Bing as well as Google helps.
  • Pages that answer a question clearly, near the top, from a source that looks trustworthy are the easiest to quote.

Search used to be ten blue links and a fight for position one. Now a lot of people ask a question and read one answer. The good news: those answers are built from web pages, and many tools show which ones. So you can still be the source. You just have to be an easy one.

How it roughly works

  1. The question gets rewritten into one or more searches.
  2. The tool searches the web, through its own index or a search provider.
  3. It picks a few pages that look relevant and trustworthy, and reads the useful parts.
  4. It writes an answer, usually with links to the pages it used.

Every step can drop you. If you’re not found, you’re not read. If you’re read but vague, you’re not quoted.

First checks on your own site

  • Are the crawlers allowed? Open yoursite.com/robots.txt. Make sure you’re not blocking the bots that power AI search, such as OAI-SearchBot (ChatGPT search), PerplexityBot and Googlebot. Blocking training crawlers is a separate choice from blocking search ones.
  • Are you indexed in Bing too? ChatGPT search uses third-party search providers, so set up Bing Webmaster Tools as well as Google Search Console. It takes ten minutes.
  • Is the text real text? Words inside images, PDFs and heavy scripts are hard to read. Important answers should be plain HTML.
  • Do your pages load fast and without a login? A tool on a time budget won’t wait.

What gets picked

Nobody publishes the exact recipe, and it changes. But the pattern is consistent: tools prefer pages that answer the question directly, come from a source with a track record, show who wrote them and when, and back their claims up. In other words, the things good editors always wanted. The next two lessons show how to write that way.

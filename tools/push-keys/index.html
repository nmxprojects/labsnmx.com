Notification keys

For the site owner. Makes the one key pair (VAPID) that signs your browser notifications. It runs entirely in this browser: nothing is sent anywhere.

Do this once. If you change the keys after people subscribe, every existing subscription stops working and they have to subscribe again.

1. Public key

Paste into VAPID_PUBLIC_KEY in /assets/nmx.js, and into the GitHub secret VAPID_PUBLIC_KEY. It’s safe to publish.

2. Private key

Paste only into the GitHub secret VAPID_PRIVATE_KEY. Never put it on the website or in Apps Script. Keep a copy in your password manager.

3. Subject

GitHub secret VAPID_SUBJECT: mailto:nmxprojects@gmail.com. Push services use it to contact you if something goes wrong.
